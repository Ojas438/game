Same Algorithm, More Data

100 copies of one NFL prediction algorithm. Predictor 1 learns from 0 games, predictor 100 learns from games, and the rest learn from amounts in between. Here is what each one picks.

Every predictor looks at the same four things about both teams: this season's record, the average point margin over its last 3 games, how high it picked in this year's draft (a higher number means more high picks), and players gained minus players lost in trades this year. From the games it learns from, it works out how much each one matters. The trade list only goes up to April 2026, so trades made since then are not counted.

Each predictor learns from the most recent finished games. Change a matchup, remove it, or add your own. Tap a square to see that predictor's pick.
