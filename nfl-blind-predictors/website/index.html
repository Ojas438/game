A science project

Same Algorithm, More Data

100 copies of one NFL prediction algorithm. The only difference between them is how many past games each copy learns from, from none at all up to every game since 1999. Where does more data stop helping?

This matters for AI because training on more data takes more computing, and computing uses electricity and water to cool data centers. If an AI stops getting better after a certain amount of data, everything past that point costs water for nothing.

The algorithm

All 100 predictors run this exact code. It's the same code that produced the results above, running in your browser right now.

  1. Give every team a strength rating of 0, and set the home-field bonus to 0.
  2. For each game it learns from, the predicted score margin is: home rating + home bonus − away rating.
  3. Go through the teams one at a time and set each rating to the value that best matches that team's real score margins, given its opponents' ratings. Then do the same for the home bonus.
  4. Repeat step 3 thirty times, so the ratings settle down.
  5. Every rating is pulled a little toward 0, as if each team also played 3 perfectly average games. This keeps a team that won one game by 40 from looking unbeatable.
  6. To predict a game, pick the side the formula from step 2 favors. With no data, everything is 0, so it flips a coin.
